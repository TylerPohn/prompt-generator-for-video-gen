## Article II: Platform Overview

### 2.1 Description

Anime-ass.com is an AI-powered video generation platform that enables users to create videos from text prompts and images using state-of-the-art machine learning models.

### 2.2 Core Features

- **Text-to-Video Generation:** Users input text prompts to generate AI videos
- **Image-to-Video Generation:** Users can animate still images
- **Video Browser:** S3-integrated gallery for viewing generated content
- **Prompt Lab:** Experimentation interface for testing video generation parameters

### 2.3 Technology Stack

| Component | Technology |
|-----------|------------|
| Frontend | React 19, TypeScript, Vite, TailwindCSS |
| Backend | AWS CDK, Lambda, API Gateway |
| Database | DynamoDB |
| Queue | SQS |
| Storage | S3 |
| Compute | ECS with GPU instances (g5.xlarge) |
| Hosting | Vercel (frontend), AWS (backend) |
| ML Models | Replicate API, Wan2.2-T2V |
